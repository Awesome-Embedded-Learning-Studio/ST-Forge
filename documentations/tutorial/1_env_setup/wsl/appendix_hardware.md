# 附录 — 硬件选项（WSL · Linux）

这篇是咱们置办硬件时的采购参考:Blue Pill 买什么、调试器怎么挑、配哪些零碎、怎么避开假货。笔者把规格、引脚、选购、排障拢在一起,需要时翻回来查。硬件这篇和平台无关,Windows 路线和 WSL 路线看同一份就行。

## Blue Pill 核心规格

| 参数 | 规格 |
| --- | --- |
| 微控制器 | STM32F103C8T6 |
| 内核 | ARM Cortex-M3,最高 72 MHz |
| 工作电压 | 3.3 V(板载 LDO 支持 5 V 输入) |
| Flash | 64 KB(`0x08000000` 起) |
| SRAM | 20 KB(`0x20000000` 起) |
| GPIO | 约 37 个(部分复用) |
| ADC | 12 位 |
| 定时器 | 3 个通用 + 1 个高级 |
| 通信接口 | USART ×3、SPI ×2、I2C ×2、CAN、USB 2.0 全速(设备模式) |
| 封装 | LQFP48 |

引脚的精确位置和复用映射,以 ST 数据手册的 pinout 图为准——板子版本不同会有细微差异,数据手册是唯一不骗咱们的源。

## 关键引脚速查

| 引脚 | 功能 | 备注 |
| --- | --- | --- |
| PC13 | 板载 LED | **低电平点亮**(共阳极) |
| PA9 / PA10 | USART1_TX / RX | 串口打印走这儿,接 USB-TTL |
| PA13 / PA14 | SWDIO / SWCLK | ST-Link 调试接这俩 |
| NRST | 复位 | 低电平复位 |
| PA11 / PA12 | USB_D- / D+ | 接的是 USB 外设,**不是串口** |
| BOOT0 / BOOT1 | 启动模式选择 | 见下表 |

启动模式靠 BOOT0 和 BOOT1 决定,新手最容易踩:

| BOOT0 | BOOT1 | 启动模式 |
| --- | --- | --- |
| 0 | 任意 | 从 Flash 启动(日常运行、调试都用这个) |
| 1 | 0 | 从系统存储器启动(走内置 bootloader,串口下载用) |
| 1 | 1 | 从 SRAM 启动(调试用,掉电就丢) |

记住一条:正常烧录调试 BOOT0 拨到 0;只有想用串口下载(没 ST-Link 时)才拨到 1。拨错就是经典的「代码下进去了板子没反应」。

## 电源怎么喂

| 输入 | 电压 | 说明 |
| --- | --- | --- |
| micro-USB | 5 V | 经板载 LDO(常见 AMS1117-3.3)降到 3.3 V |
| 5V 引脚 | 5 V | 直接喂 LDO 输入 |
| 3.3V 引脚 | 3.3 V | 绕过 LDO 直接喂 MCU(外接调试器供电常用) |

雷区:**别同时接两路电源**。USB 插着又从 ST-Link 的 3.3V 喂电,会倒灌烧板子。要接 ST-Link 的 3.3V,先把 USB 拔了。负载大时 USB 那 500 mA 不一定够,走外部 3.3 V 更稳。

## 调试器怎么挑

| 调试器 | 价格 | 备注 |
| --- | --- | --- |
| ST-Link 官方 | 高 | 稳定,免折腾 |
| ST-Link 克隆版 | 很低(十几块) | 功能够用,Linux 下配 udev 规则即可,不像 Windows 要换驱动 |
| DAP-Link | 中 | 开源 CMSIS-DAP,跨平台免驱动,口碑好 |
| J-Link | 高 | 专业级,性能好但贵 |

Linux/WSL 路线有个好处:ST-Link 克隆版在这边不用像 Windows 那样拿 Zadig 换驱动,配个 udev 规则就能用(见 [01 章](./01_environment_setup))。新手买个便宜的 ST-Link V2 克隆版够用;想更省心,DAP-Link 是好替代,接线和 ST-Link 一样。

## 还要配哪些零碎

- **USB-TTL 串口模块**(CH340 / CP2102 / FT232):看 `printf` 必备,接 PA9/PA10。模块逻辑电平得 3.3 V,5 V 的要电平转换;RX 接 TX、TX 接 RX 交叉接。Linux 下对应 `/dev/ttyUSB0` 之类设备。
- **杜邦线**:母对母为主,备点母对公、公对公。
- **面包板**:830 孔标准款。
- **USB 数据线**:**得是能传数据的线**,不是充电线。

## 采购避坑

**芯片真伪**。便宜 Blue Pill 上的芯片有真有假,甚至有打磨翻新的拆机片。粗判:正品印刷清晰、字体规范、引脚镀层均匀;可疑的字体模糊、标识歪斜、有打磨痕。实锤用 STM32CubeProgrammer 或 OpenOCD 读芯片唯一 ID。

**虚假容量**。山寨板声称更大 Flash/SRAM,实际看芯片型号——`C8T6` 就是 64 KB。

**板子质量**。焊点均匀饱满、PCB 边缘干净、元器件不歪斜;USB 座松动的别买。

**调试器**。确认支持 SWD、附带接线;超低价的某些克隆版有功能缺陷,挑评论多的买。

入门最小清单:一块 Blue Pill、一个 ST-Link V2(含线)、一根数据线、一块面包板、一套杜邦线。串口模块和万用表建议也备上。

## 硬件排障速查

**USB 不识别 Blue Pill**。先怀疑数据线(换能传数据的)、再查供电(量 3.3 V 引脚)、最后看 D+/D- 电路。记住 Blue Pill 的 micro-USB 接的是 USB 外设不是串口,插上 USB 看不到串口打印是正常的,得另接 USB-TTL。

**调试器连不上芯片**。查四样:SWDIO/SWCLK/GND 接对没、共地没、BOOT0 在不在 0、杜邦线别太长。还不行按住复位键的同时发起连接。WSL 还得多查一步:ST-Link attach 了没。

**芯片发烫**。多半短路或供电过高,立刻断电。目视查焊点桥接,量电源引脚对地电阻,拔掉外设只留最小系统再上电。

**电源不稳、程序乱跑**。多半供电不足或退耦缺失,加 0.1 µF + 10 µF 滤波,大电流外设走独立电源,接地要牢。
