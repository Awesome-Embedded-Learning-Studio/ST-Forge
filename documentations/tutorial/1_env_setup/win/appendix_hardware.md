# 附录 — 硬件选项

这篇是咱们置办硬件时的采购参考:Blue Pill 到底买什么、调试器怎么挑、还要配哪些零碎、怎么避开假货和坑货。笔者把规格、引脚、选购和排障拢在一起,需要的时候翻回来查就行。

## Blue Pill 核心规格

| 参数 | 规格 |
| --- | --- |
| 微控制器 | STM32F103C8T6 |
| 内核 | ARM Cortex-M3,最高 72 MHz |
| 工作电压 | 3.3 V(板载 LDO 支持 5 V 输入) |
| Flash | 64 KB(`0x08000000` 起) |
| SRAM | 20 KB(`0x20000000` 起) |
| GPIO | 约 37 个(部分复用) |
| ADC | 12 位 |
| 定时器 | 3 个通用 + 1 个高级 |
| 通信接口 | USART ×3、SPI ×2、I2C ×2、CAN、USB 2.0 全速(设备模式) |
| 封装 | LQFP48 |

引脚的精确位置和复用映射,笔者建议以 ST 数据手册的 pinout 图为准——板子版本不同会有细微差异,数据手册是唯一不会骗咱们的源。

## 关键引脚速查

这几个引脚整条课程会反复用到,先记住:

| 引脚 | 功能 | 备注 |
| --- | --- | --- |
| PC13 | 板载 LED | **低电平点亮**(共阳极) |
| PA9 / PA10 | USART1_TX / RX | 串口打印走这儿,接 USB-TTL |
| PA13 / PA14 | SWDIO / SWCLK | ST-Link 调试接这俩 |
| NRST | 复位 | 低电平复位 |
| PA11 / PA12 | USB_D- / D+ | 接的是 USB 外设,**不是串口** |
| BOOT0 / BOOT1 | 启动模式选择 | 见下表 |

启动模式靠 BOOT0 和 BOOT1 两个跳线决定,这是新手最容易踩的坑之一:

| BOOT0 | BOOT1 | 启动模式 |
| --- | --- | --- |
| 0 | 任意 | 从 Flash 启动(咱们日常运行、调试都用这个) |
| 1 | 0 | 从系统存储器启动(走芯片内置 bootloader,串口下载用) |
| 1 | 1 | 从 SRAM 启动(调试用,掉电就丢) |

记住一条:正常烧录和调试时 BOOT0 拨到 0;只有想用串口下载(没有 ST-Link 时)才拨到 1。拨错了就是经典的「代码下进去了板子没反应」。

## 电源怎么喂

Blue Pill 有好几种供电方式,笔者拢一下:

| 输入 | 电压 | 说明 |
| --- | --- | --- |
| micro-USB | 5 V | 经板载 LDO(常见 AMS1117-3.3)降到 3.3 V |
| 5V 引脚 | 5 V | 直接喂 LDO 输入 |
| 3.3V 引脚 | 3.3 V | 绕过 LDO,直接喂 MCU(外接调试器供电时常用) |

有个雷区笔者必须点:**别同时接两路电源**。比如 USB 插着又从 ST-Link 的 3.3V 喂电,两路会倒灌,板子可能就这么废了。要接 ST-Link 的 3.3V,就先把 USB 拔了。负载电流大(比如带一堆外设)时,USB 那 500 mA 不一定够,走外部 3.3 V 电源更稳。

## 调试器怎么挑

ST-Link V2 是最常用的,咱们这套环境就指着它。市面上分官方版和克隆版:

| 调试器 | 价格 | 备注 |
| --- | --- | --- |
| ST-Link 官方 | 高 | 免驱动折腾,稳定 |
| ST-Link 克隆版 | 很低(十几块) | 功能够用,但 Windows 上常得拿 Zadig 换 WinUSB 驱动(见 [01 章](./01_environment_setup)) |
| DAP-Link | 中 | 开源,CMSIS-DAP 协议,跨平台免驱动,口碑很好 |
| J-Link | 高 | 专业级,SEGGER 出品,性能好但贵 |

笔者对新手的最省心建议:买个便宜的 ST-Link V2 克隆版练手完全够;要是嫌 Windows 驱动折腾,DAP-Link 是更省心的替代,接线方式和 ST-Link 一模一样(都是 SWD 那几根线)。

## 还要配哪些零碎

- **USB-TTL 串口模块**(CH340 / CP2102 / FT232 都行,几块钱):看 `printf` 输出必备,接到 PA9/PA10。注意模块逻辑电平得是 3.3 V,5 V 的要电平转换;接线 RX 接 TX、TX 接 RX 交叉接。
- **杜邦线**:母对母为主(ST-Link 接 Blue Pill),备点母对公、公对公。
- **面包板**:830 孔标准款,接外设用。
- **USB 数据线**:再三强调,**得是能传数据的线**,不是充电线。这个坑坑过的人不计其数。

## 采购避坑

笔者把几个常见的雷摆出来,掏钱前心里有数。

**芯片真伪**。便宜 Blue Pill 上的芯片有真有假,有的甚至是打磨翻新的拆机片。粗判:正品印刷清晰、字体规范、引脚镀层均匀;可疑的字体模糊、标识歪斜、有打磨痕。想实锤,用 STM32CubeProgrammer 或 OpenOCD 读一下芯片的唯一 ID,能读出来且行为正常,基本就稳了。

**虚假容量**。有些山寨板声称更大 Flash/SRAM,实际看芯片型号才是准的——`C8T6` 就是 64 KB,改不了。

**板子质量**。焊点均匀饱满、PCB 边缘干净、元器件不歪斜;USB 座松动的别买,接触不良能折磨人到怀疑人生。

**调试器**。确认支持 SWD、附带接线;超低价的某些克隆版存在功能缺陷,挑评论多的买。

入门最小采购清单:一块 Blue Pill、一个 ST-Link V2(含线)、一根数据线、一块面包板、一套杜邦线。串口模块和万用表建议也备上,后面调试少不了。

## 硬件排障速查

**USB 不识别 Blue Pill**。先怀疑数据线(换成已知能传数据的)、再查供电(量一下 3.3 V 引脚电压)、最后看 D+/D- 电路——有些板子 D+ 上那颗 1.5 kΩ 上拉电阻有问题。另外记住,Blue Pill 的 micro-USB 接的是 USB 外设,不是串口,指望插上 USB 就看到串口打印是没门的,得另接 USB-TTL。

**调试器连不上芯片**。查四样:SWDIO/SWCLK/GND 接对没、共地了没、BOOT0 在不在 0、杜邦线别太长(长了信号衰减)。还不行就按住复位键的同时发起连接,有时能把卡死的芯片拽回来。

**芯片发烫**。多半是短路或供电过高,立刻断电。目视查焊点有没有桥接,量各电源引脚对地电阻,把外设全拔了只留最小系统再上电。

**电源不稳、程序乱跑**。多半是供电不足或退耦缺失,加个 0.1 µF + 10 µF 滤波电容,大电流外设走独立电源,接地要牢。
