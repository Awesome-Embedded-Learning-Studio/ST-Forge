# 🪟 Windows 原生路径

这条路径带咱们在**原生 Windows** 上把 STM32F103C8T6 的开发环境搭起来:ARM GCC 工具链、CMake、OpenOCD、ST-Link 驱动、VS Code + Cortex-Debug,一整套都在 Windows 下装好、配好,不碰 WSL。

适合不想折腾 WSL、希望工具装得更直观的朋友。笔者说实话,第一次搞嵌入式,从这条路径起步最省心。

👇 从头开始:[01 — 环境配置(Windows 原生) →](./01_environment_setup)

> **侧边栏里两组长得很像的章节,是怎么回事?**
> 本教程按**开发平台**分了 🪟 Windows 原生 和 🐧 WSL · Linux 两条路径,章节结构一模一样,但每篇里的命令、驱动、USB 权限处理全是各管各的。**咱们按自己的系统选一条走完就行,两套都看没必要。** 更习惯 Linux 那套工具体验?那就去 [🐧 WSL · Linux 路径](../wsl/)。
