# P0 · 课程准备与硬件心智模型

这是整条课程的第一站，它一行代码都不写，只做一件事——在咱们脑子里把「单片机到底是什么」这层认识立正。

笔者见过太多人学 STM32 的挫败，根子不在哪个外设太难，而在一开始就没分清 ARM 和 ST 是什么关系、Cortex-M3 和 STM32 是什么关系、出了问题该翻哪本书。这层认识没立起来，后面每学一个外设都像在背一坨孤立的 API，撞了坑只能拿搜索引擎碰运气。本篇就是来把这个地基打掉的。

走完这一段，咱们要做到：说清 ST、STM32、F1、F103、C8T6、Cortex-M3、Blue Pill 这堆名词谁是谁；知道出了问题该回到哪三本官方文档里翻答案；在脑子里立起「单片机就是一台小计算机」的系统视角，后面每个外设都是这台计算机的一个零件；还要对 Blue Pill 这块板子的关键参数和几个新手必踩的坑，先留下第一印象。

## 和「环境配置」那块的关系

如果咱们是顺着[环境配置](../1_env_setup/)一路点进来的，笔者在这儿把两边的分工说清楚：那边解决的是「工具链怎么装、工程怎么跑起来」，是**操作**；本篇解决的是「咱们在给一块什么芯片装工具、为什么要装这些」，是**心智**。两边不打架，但笔者建议先把 P0.1 读完再回去配环境——那时候咱们会更清楚每一步到底是在干什么。
